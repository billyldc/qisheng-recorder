# 七圣召唤录制器

把收藏的七圣召唤对局，批量录成带游戏声音的视频。

为 Mac 上的云原神回放录制设计。选好对局后，应用会依次播放、录制并保存，省去一局局手动开关录屏的操作。**这是回放录制工具，不是自动打牌工具。**

[安装包](https://github.com/billyldc/qisheng-recorder/releases) · [快速上手](#快速上手) · [常见问题](#常见问题) · [反馈问题](https://github.com/billyldc/qisheng-recorder/issues)

> 当前正在准备 1.6.0 候选版，尚未发布正式安装包。录制和识别功能保留；双视角合成仍是实验脚本，尚未接入应用。

## 可以做什么

- **批量录制收藏对局**：勾选想保存的对局，逐局生成视频。
- **自动整理文件名**：识别对局日期、模式和双方角色，录制前可以手动修改。
- **录下完整画面和游戏声音**：可以选整个游戏窗口，也可以自己框选范围。
- **录完再核对角色**：结合录像中的多个清晰画面检查角色，拿不准的结果留给你确认；已有录像也能导入。
- **浏览角色库**：按名字查找参考卡图，点击查看大图，区分内置图片和后来下载的图片。
- **随时停止并保存**：悬浮窗显示当前进度，点击「停止并保存」即可结束，不会录进悬浮提示。
- **云原神保活**：录制时可定期移动鼠标，也可以单独开启「只保活」，尝试避免长时间无操作掉线。

## 下载与安装

需要 **macOS 15 或更新版本，以及 Apple 芯片的 Mac（M 系列）**。目前不提供 Windows 或 Intel Mac 安装包。

1. 正式版发布后，在[下载页面](https://github.com/billyldc/qisheng-recorder/releases)下载附件中的 **`.dmg`**。不要选 `Source code`，那是源代码。
2. 打开安装包，把 **Qisheng Recorder** 拖入「应用程序」，然后从那里启动。
3. 按「首次设置」提示，开启 **屏幕与系统音频录制** 和 **辅助功能**。前者用于录屏和录音，后者用于点击回放按钮。
4. 选择游戏所在的应用和视频保存位置。默认保存在个人文件夹的「影片 → 七圣召唤」。

**录制不需要额外安装 OBS、Hammerspoon 或 Python。** 如果系统要求退出后重新打开，请照提示操作。

## 快速上手

1. **打开收藏列表**：在游戏中进入七圣召唤的「收藏对局」页面。
2. **选好画面**：第一次推荐选择「全窗口」，再选游戏窗口。如果只想录窗口的一部分，用「手动选框」，拖出范围后按回车确认，Esc 取消。
3. **核对并勾选对局**：检查日期、模式和角色名称；识别错了可以直接改，「未识别」也不妨碍录制。
4. **先试录一次**：点击「试录 10 秒」，播放生成的视频，确认边框完整、游戏声音正常。
5. **开始录制**：勾选要录的对局，点击「开始录制」。需要结束时，点击悬浮窗的「停止并保存」。

全窗口模式会先确认官方云原神内容区，排除浏览器工具栏，再用连续三张画面检查黑边。不按固定比例裁切；边缘不稳定或画面过暗时保留边缘，无法确认网页内容区时请改用手动选框。预览、按钮定位和录制使用同一范围。录制期间不要切换游戏标签、滚动收藏列表或调整窗口大小，也不要锁屏、合盖或最小化游戏窗口。

全窗口的游戏画面会在每局结束后导出；完整窗口原片保留在输出目录的「原始窗口」子目录，因此会多占一份磁盘空间。导出失败不会删除原片。手动选框不再追加裁切。

“正在保存画面”不等于已切换到对方视角。悬浮窗会单独显示“视角待确认”；只有确认视角和继续播放后才显示对方视角。未进入回放、视频写入停滞、持续暂停或画面长时间卡住时，会停止并保留片段，不计为完整对局。

## 按需要开启

### 从 Safari 启动并录制

在「录制对局」点击「启动 Safari 并录制」。应用会打开或恢复官方云原神网页，沿用 Safari 中的登录状态。

需要自动登录时，在「首次设置 → 云原神账号」配置账号和密码。它们仅存入当前 Mac 的钥匙串；开启自动登录后，应用会先从验证码登录切换到密码登录，再逐字模拟键盘输入并提交一次。输入时请暂勿操作键盘或切换窗口；窗口或输入框失去焦点会停止。密码不经过剪贴板。验证码仍需你在 Safari 完成。可以随时关闭自动登录或移除已保存账号。

不想每次手动勾选登录协议时，阅读旁边链接的官方用户协议和隐私政策，再开启「同意官方协议，并在登录时自动勾选」。此选项默认关闭，可随时在首次设置关闭；只自动勾选可确认的官方登录协议，不勾选其他授权。

macOS 首次询问钥匙串访问时，输入该钥匙串密码并选择「始终允许」，而不只是「允许」。成功读取后，应用仅在本次解锁会话内复用账号，锁屏、锁定钥匙串、切换用户、休眠或退出后清除内存副本。更新应用或重新锁定钥匙串后，macOS 仍可能再次确认；应用不会绕过系统确认，也不会把密码另外存到文件。

在可识别的正常游戏画面中，应用会尝试打开地图，选择蒙德并传送到猫尾酒馆，靠近小王子后进入回放和收藏对局。地图、传送按钮或游戏状态无法确认时会停止并提示，不会盲目操作；验证码等情况仍需手动处理。确认收藏页面和播放按钮后，3 秒倒计时结束即以全窗口录制当前页全部对局，不自动翻页。上方入口录当前页全部对局；需要保留逐局勾选、视角或人工角色修正时，用下方「开始录制」。

### 二倍速录制

在录制页勾选「自动点击二倍速」。录制期间会复核倍速，明确识别到仍为普通速度时有限重试；多次未成功仍会保存录像，并在运行日志提示核对。如果点不到按钮，可以手动校准；不需要二倍速就保持关闭。

### 只保活，不录制

先在浏览器切到原神标签页，再点击「只保活」。尚未校准时会让你选择窗口，选好立即开始，不需要先识别对局。每次重新打开应用后需要重新选择；也可以用「校准保活页面」更换目标。

它会定期切回该页面并移动鼠标，可能打断你使用其他应用。若应用提示只能绑定当前页面，切换标签或刷新页面后会停止，需要重新选择。关闭主窗口不会停止，请用「停止保活」结束；锁屏或退出应用也会停止。

### 选择录制视角

每个收藏对局都可以选择「己方视角」或「对方视角」，默认己方。己方不暂停、不切换；对方会在二倍速操作后等待掷骰结束、牌桌菜单出现，先暂停，确认暂停后切换视角，再点击「继续」并确认恢复播放。如果暂时无法切换，会先恢复播放，再等待下一次机会，不会因找不到按钮直接停止录制。等待期间照常录制，因此开头仍可能有己方画面。

应用通过连续画面中的上下牌手位置判断视角，不依赖可能不变的菜单文字。视角读不清但回放已继续时，会保留录像并标记待核对，不会盲目反复切换。若始终无法恢复播放，仍可手动停止保存，单局时长上限也继续有效。

录制页顶部开启「双方视角录制」后，会先录全部已勾选对局的己方视角，再录全部对方视角，例如己方 1–5、对方 1–5。此时暂不使用每局的单独选择，关闭开关后恢复。文件名会区分视角，角色名称仍按原对局的己方、对方保存；整批两轮录完后才结束录制保活。

### 更新角色库

侧栏「角色库」可以直接浏览图片、搜索角色并点击放大。每个角色条目展示一张用于识别的参考卡图，不是录像截图；只浏览不需要联网。

新角色认不出来时，在「首次设置」点击「更新角色库」。也可以开启每天自动检查。更新失败仍可录制，角色名称可以手动填写。

### 复核已有录像

在「已录视频」中点击「导入录像复核」。完成后点击铅笔按钮查看候选角色和截图，修改并标记「人工确认」。这不会改动原视频或文件名。

## 常见问题

### 下载后打不开，或更新后又要授权？

当前安装包尚未通过 Apple 公证，macOS 可能提示无法验证开发者。请先确认下载来源是本仓库，再按「系统设置 → 隐私与安全性」中的提示操作，不要关闭系统安全保护。

更新后系统也可能要求重新授权。请始终从「应用程序」中打开录制器，并按提示退出、重新打开。

### 怎么更新应用？

优先点击侧栏或应用菜单中的「检查更新」，在原位置完成更新。当前入口使用 GitHub CLI；仓库私有期间，需要本机已登录且有仓库访问权限。检查更新不会自动安装，需要你确认。正式安装包也会放在[下载页面](https://github.com/billyldc/qisheng-recorder/releases)。

此仓库与其他开发仓库独立发行；更新只检查本仓库的正式版，不会安装实验分支或候选版。系统是否沿用授权仍取决于签名和 macOS，不承诺更新后绝不再询问。

### 为什么角色名是「未识别」？

头像太小、画面被遮挡或角色库尚未更新，都可能影响识别。可以先修改名称，也可以录完后查看复核结果。不确定时应用会保留待确认状态，不保证每一局都能自动认全。

### 能断开远程桌面，让 Mac mini 继续录吗？

可以尝试「全窗口」配合「无人值守」。防休眠和后台运行保护由录制所在的 Mac 申请，不由观看端电脑承担。录制电脑必须保持登录、解锁，游戏也不能最小化；远程断开若同时锁屏或让虚拟显示器消失，录制仍会停止。日志会区分显示器休眠、会话改变和捕获中断。首次使用请先做一次短时间断连测试；不能保证所有远程桌面模式在观看端关屏后仍可录制。

### 录像和角色识别会上传到哪里？

录像和角色识别都在本机处理，应用不会自动上传截图、视频或识别结果。检查应用更新和角色库更新时需要联网。

### 怎么快速停止？

点击悬浮窗或菜单栏里的「停止并保存」，也可以按 **`Cmd + Shift + S`**。**`Cmd + Shift + R`** 可以重新显示主窗口。关闭主窗口不等于停止录制。
