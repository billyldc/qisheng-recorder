# 发行副本的隐私检查

此仓库从独立的源码快照开始，不包含其他仓库的提交、分支、标签、远程配置或历史发布附件。后续同步流程见 [RELEASING.md](RELEASING.md)。

## 不随源码和安装包分发

- 私人操作记录、代理指引、诊断日志、录像、游戏截图和真实对局的头像测试夹具。
- 个人配置、浏览器资料、账号密码、GitHub 令牌、证书私钥和钥匙串。
- 用户机器上的 Python 环境、应用缓存和历史安装包。构建环境重新建立，安装包只收录明确指定的产物。
- 测试中的真实对局日期；改用虚构日期，不影响日期解析和录制流程检查。

仓库保留公开的 GitHub 所有者名称、noreply 提交邮箱和已有 Bundle ID。它们不是登录凭据；保留 Bundle ID 是为了避免不必要的应用身份迁移，不保证系统权限自动继承。

## 角色识别的数据去向

角色识别使用系统 OCR 和本地 OpenCV 图像匹配，不向外部 AI 服务发送画面，也不含 AI 服务密钥。145 张内置角色参考图及独立的菜单图标已人工查看；它们是游戏美术资源，不是带玩家信息的截图，权属说明见第三方声明。

图库更新从公开资料源下载图片，应用更新访问本仓库。自动登录使用用户自己配置的钥匙串条目与官方登录页面。这些功能没有携带开发者账号或密码。用户自己的录像、复核截图和日志仍可能包含个人信息，分享前需要自行检查。

## 检查方式与限制

公开前已重新核对全部远程分支、标签、提交历史、六个已发布版本的 ZIP/DMG，以及可下载的 Actions 日志。安装包的签名证书仅含应用名称，不含个人姓名或邮箱；签名私钥不在分发内容中。源码图片均为角色参考美术和一个菜单图标，没有分发真实玩家画面。

- `privacy_audit.py --tree .` 检查源码，`privacy_audit.py .` 检查全部 Git 历史。
- 构建会检查原生程序、资源、图片元数据及冻结 Python 模块，包括 `base_library.zip`。
- 第三方库中的公开示例地址、上游构建路径和库自测密钥片段，逐项与原始官方依赖核对。例外只匹配指定文件或模块中的指定内容摘要，记录在 `scripts/dependency_privacy_reviews.json`；不是跳过整个依赖。新内容或其他路径仍会失败。
- 可使用私存的 `--deny-file` 加查个人标识。此清单不能提交；它不受依赖例外影响。
- 正则、摘要检查和人工查看不能保证发现所有隐私。以后新增图片、模型、附件或改为公开前，仍需重新检查，不可把本次检查当作永久保证。

构建和离线测试不代表完整游戏流程已实机验收。当前公开版的功能限制见 [RELEASE-1.6.6.md](RELEASE-1.6.6.md)。
