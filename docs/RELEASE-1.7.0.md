# 1.7.0：录制免打扰与等待恢复

## 主要变化

- 默认开录前开启并确认系统勿扰，暂时覆盖其他专注模式；保存或停止后
  恢复原模式。确认失败会等待检查，不会悄悄在无保护状态下开录。
- 全窗口录制被其他窗口盖住或暂时失焦时继续保存画面；自动点击等待
  遮挡消失，重新识别后再操作，不再把暂时不能点击当作录制失败。
- 手动选框排除通知中心、控制中心和录制器窗口。普通应用切入仍会
  停止，防止录进无关内容；推荐全窗口录制。
- 每局可分别选己方、对方或双方视角，支持只补录选中的对局。
- 看不清启动页面、播放或视角状态时显示等待/待核对，不假装已经成功。
  室外进入猫尾酒馆仍需手动协助，不再猜测地图入口。
- 改进浏览器窗口和标签页去重，重新检查全屏工具栏变化后的保活目标，
  不再把同一个标签的多个辅助功能路径计为多个标签。

## 使用前留意

在系统勿扰中关闭允许的联系人、App、时效性和智能放行，才能静音普通
消息。紧急提醒与系统安全弹窗不保证可屏蔽。不会修改跨设备共享设置、
关闭系统安全服务或重建专注模式倒计时。录制中手动更改模式会被保留。

请通过应用内「检查更新」更新；本次未替换任何已安装应用，也未重置权限。
安装包沿用固定本地签名，但尚未 Apple 公证，系统仍可能要求确认。

## 验证与限制

核心状态机覆盖逐局排队、异常观测、视角切换及通知焦点例外；另外提供
假勿扰恢复、保活身份及合成窗口录制测试。这些不等于新的真实游戏整批
验收。长期云游戏保活、任意地点自动导航及观看端断连仍需实际环境确认。

独立浏览器内部音视频实验通过全遮挡、真实失焦与逐帧/声音检查，但系统
通知未实际显示，真实云原神和 Safari 尚未验证。浏览器录制后端与智能
双视角合成都**没有接入本版**，见[浏览器实验](BROWSER-CAPTURE.md)。

录像、角色识别及复核仍在本机完成，不自动上传游戏画面。
