# 1.6.6

首个公开版本，提供 Apple 芯片 Mac 的安装包，要求 macOS 15 或更新版本。建议先从游戏里的「收藏对局」页面开始，试录十秒确认画面和声音，再批量录制。

## 主要功能

- 批量录制收藏对局，保存游戏声音并按日期、模式、角色命名。
- 逐局选择己方或对方视角，也可以分两轮录制双方视角。
- 录后用多个画面复核角色，允许人工修改；识别失败不会阻止录像保存。
- 浏览与更新角色参考库，单独开启保活，使用悬浮窗停止并保存。
- 可尝试通过 Safari 启动官方云原神；自动登录为可选功能，账号密码由用户自行配置并保存在本机钥匙串。

## 验证范围

在一个 Safari 环境中，从小王子附近继续进入收藏列表并连续录完五局对方视角。五个成片均能完整解码，含非静音音轨；多个时刻检查了视角、播放推进及结算画面，导出画面未包含浏览器工具栏。启动到小王子附近的过程有人工协助，不是完整无人值守启动验收。

核心检查、28 种视角与播放模拟场景通过；worker 测试 62 项通过，4 项依赖未分发的私人截图，明确跳过。模拟和离线测试不替代真实游戏验证，也不能保证所有设备和窗口布局均适用。

## 已知限制

- 对方视角需要等可切换时机，开始部分可能保留己方画面或动画；没有录到的开局信息无法补回。
- 从其他地点自动传送到收藏列表、长期云游戏保活、观看端关屏或断连，尚未完成完整验证。录制电脑仍需保持登录、解锁。
- 自动二倍速依赖可见按钮和识别结果，请检查成片；本次只有多时刻抽样，不是全片连续倍速验收。
- 双视角合成仍是需要人工复核时间对应关系的实验脚本，没有可靠的自动同步或应用内自动合并。
- 当前安装包使用自签名证书，未通过 Apple 公证；请确认下载来源，并按系统提示操作，不要关闭系统安全保护。
- 应用内更新仍需安装并登录 GitHub CLI；也可直接从公开 Releases 下载。

## 隐私

角色识别和录像复核在本机处理，不调用外部 AI 服务。图库更新仅下载公开参考资料；自动登录只向可确认的官方页面输入用户配置的账号。源码和安装包不包含开发者的登录资料、真实录像、私人截图或签名私钥。

用户自己生成的录像、原始窗口、日志和复核截图可能包含 UID、昵称或本机路径，反馈问题前请遮挡或删除这些内容。检查方式及限制见 [隐私检查说明](PRIVACY-REVIEW.md)。
