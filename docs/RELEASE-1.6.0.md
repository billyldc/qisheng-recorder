# 1.6.0 候选版

这是历史候选记录；当前公开版本请看 [1.6.6](RELEASE-1.6.6.md)。

这是独立发行仓库的首个候选版本，目前尚未正式发布。

保留批量录制、双方视角选择、录后角色复核、角色库浏览、Safari 启动和单独保活。对方视角尝试在掷骰结束后先暂停，再切换并恢复播放。

源码与发行流程独立整理：不携带开发仓库历史、私人截图、录像、账号配置或证书；构建默认不读取本机签名配置。角色识别仍在本机完成，不调用云端 AI。更新入口只指向本仓库。

双视角合成仅提供实验脚本，可以把对方手牌和双方骰子放入同一牌桌画面，但时间对应关系仍需人工核对，尚无应用内自动合并。

正式发布前仍需完成此候选包的实机录制、视角切换、声音和应用内更新验收。自动二倍速可能受窗口布局影响。当前开发包未通过 Apple 公证，不要关闭系统安全保护。
